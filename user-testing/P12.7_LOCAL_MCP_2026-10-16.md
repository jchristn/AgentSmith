## Isolation and attempts

- A separate temporary Hugo database, master key, random loopback port, synthetic target database, and
  profile-locked credential were used. The operator account remained inside this disposable fixture.
- mux used a temporary `--config-dir`, `--strict-mcp-config`, no project instructions, no session
  persistence, and a tool allowlist containing only the four calls above. No user client configuration,
  authentication, or trust settings were edited.
- A temporary loopback proxy kept the private model address exclusively in process memory/environment.
  It forwarded real native Ollama requests and set `think=false`, `num_ctx=32768`, and
  `num_predict=2048`. Sanitized metadata records all four actual model requests.
- The first mux attempt used its `read-only` sandbox, which conservatively removed unknown external
  MCP tools. Acceptance correctly rejected that zero-tool answer. The accepted run used the explicit
  four-tool allowlist with mux's normal sandbox posture; Hugo still classified and recorded both SQL
  calls as Read.
- Codex CLI 0.163.0 with the same real model was also tried using `--oss`, isolated CLI overrides,
  `--ignore-user-config`, `--ignore-rules`, `--ephemeral`, and `--no-daemon`. It initialized correctly,
  discovered all 44 tools, and actually called `hugo_get_instructions` and `hugo_list_resources`.
  Its slow run was deliberately stopped before SQL calls and a final answer. It is **partial**, not
  claimed as the successful acceptance run. Its diagnostics also contain model-list decoding warnings;
  this was not a Hugo MCP failure.
- Credentials and private network addresses are redacted in retained evidence. Generated em-dash
  punctuation is normalized to hyphens. Temporary server/client processes and credential/config files
  were removed after evidence capture; the shared Ollama service was left running.

order counts. Preparing the fixture requires the normal REST resource/profile APIs and the exact
scenario described above; the temporary state file is never committed.
