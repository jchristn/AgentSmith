# Hugo

Hugo is a multi-tenant super agent server that connects agents to the systems behind your production stack over MCP, A2A, REST, and a built-in chat dashboard. Source, documentation, and the full quick start live at [github.com/jchristn/AgentSmith](https://github.com/jchristn/AgentSmith).

Images will be published as `jchristn/hugo-server` and `jchristn/hugo-dashboard` once the first alpha is released.
